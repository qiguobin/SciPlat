# SciPlat — 博士生科研项目与论文管理平台（没事闲的Vibe Coding一下）

本地单机运行的科研管理 Web 应用，覆盖博士生科研全流程：**学生档案、项目阶段化、论文、材料、文献、日程待办、灵感收集、成果管理**。

- 数据全部存储在本机（SQLite + 文件目录），无需登录，开箱即用
- 数据模型与目录结构为 AI 技能集成（deep-research、academic-paper 等 ZCode 学术技能链）预留接口

## 快速开始

### 方式一：一键启动（推荐）

Windows 双击 `scripts\start.bat`，或 Git Bash 运行 `bash scripts/start.sh`。

脚本会自动：创建虚拟环境 → 安装后端依赖 → 构建前端 → 启动服务并打开浏览器。
首次运行需要几分钟（安装依赖 + 构建前端），之后秒级启动。

浏览器访问：**http://127.0.0.1:8000**

### 方式二：手动启动

```bash
# 后端
cd backend
python -m venv ../.venv            # 首次
../.venv/Scripts/pip install -r requirements.txt
python run.py                      # http://127.0.0.1:8000

# 前端（开发模式，热更新；另开一个终端）
cd frontend
npm install                        # 首次
npm run dev                        # http://127.0.0.1:5173
```

### 运行测试

```bash
cd backend
python -m pytest tests/ -q
```

## 数据存放位置

- 数据库：`data/sci.db`
- 上传文件：`data/files/`（UUID 目录，原文件名保留）
- 可通过环境变量 `SCI_DATA_DIR` 指定其他数据目录；端口用 `SCI_PORT` 覆盖

## 项目结构

```

│   ├── app/
│   │   ├── main.py            # FastAPI 入口 + 前端静态托管

```

## 二期 AI 集成预留接口

一期为纯管理平台，以下结构为二期接入 ZCode 学术技能链（deep-research、academic-paper、nature-* 等）预留：

1. **`GET /api/ai/capabilities`** — 返回项目/论文/材料索引与各项目导出地址，供 AI 技能直接消费
2. **结构化导出** — `GET /api/projects/{id}/export` 导出 zip，按 `docs/ data/ code/ figures/` 目录组织 + README 索引，与学术技能链的文件约定对齐
3. **存储抽象层** — `backend/app/services/storage.py` 独立接口，可平滑替换为远端存储或直接映射到工作区目录

## 常见问题

- **DOI 获取失败**：需要外网访问 CrossRef；离线时手动填写元数据即可
- **重新构建前端**：删除 `frontend/dist` 目录后再次运行启动脚本
- **备份**：整个 `data/` 目录即全部数据，复制即可迁移
